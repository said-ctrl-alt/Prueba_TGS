Unidad 03 · Tema 01

Clasificación de los sistemas

Un mismo sistema puede pertenecer a varias categorías. La clasificación depende del criterio que elijas para estudiarlo.

Criterios para clasificar un sistema
CriterioCategoríasEjemplo o distinción
ComposiciónFísico o abstractoServidor físico / modelo de asignación de cupos
ComportamientoDeterminista o probabilísticoAlgoritmo con entradas fijas / simulación con llegadas aleatorias
ComplejidadDe simple a complejoInterruptor / red de transporte con rutas interdependientes
IntercambioAbierto, cerrado o aisladoSe distingue qué cruza la frontera. En termodinámica, el cerrado puede intercambiar energía; el aislado no intercambia materia ni energía.

Intercambio con el entorno

Un sistema abierto intercambia materia, energía o información con su entorno. En termodinámica, un sistema cerrado intercambia energía, pero no materia. Un recipiente sellado que se calienta ilustra este último caso.

Comportamiento y complejidad

Un modelo determinista produce el mismo resultado para las mismas condiciones iniciales. Un modelo probabilístico describe resultados mediante probabilidades. La complejidad, en cambio, depende de las relaciones y funciones que se estudian.

Origen

Los sistemas naturales surgen de procesos de la naturaleza, como un ecosistema. Los artificiales se crean mediante intervención humana, como un sistema de préstamo bibliotecario.

Naturaleza de sus componentes

Los sistemas concretos tienen componentes físicos, como un equipo de cómputo. Los abstractos se componen de conceptos, relaciones o reglas, como un modelo matemático.

Enfoque de análisis

Un enfoque duro parte de un objetivo definido y medible, como reducir el tiempo de respuesta de un servidor. Un enfoque blando ayuda a entender situaciones en las que las personas involucradas tienen distintas ideas sobre el problema o su solución, como acordar qué debe priorizar una plataforma académica.

Lectura base · Antonio Flórez y Javier Thomas (1993), La teoría general de sistemas. Sección 6. Ver PDF.
