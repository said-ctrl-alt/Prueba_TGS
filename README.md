# ProyectoTGS

Guía de estudio de Teoría General de Sistemas construida con HTML, CSS y JavaScript nativos. No requiere instalación, servidor, compilación ni dependencias.

## Uso

Abre `index.html` directamente en un navegador o publica el contenido del repositorio en GitHub Pages. Los enlaces a las páginas y los recursos son relativos para funcionar tanto bajo una ruta de proyecto de GitHub Pages como desde archivos locales.

## Rutas

- `index.html`: inicio.
- `fundamentos/`: fundamentos de la teoría general de sistemas.
- `unidad-3/`: índice de la unidad y temas de clasificación, elementos y propiedades.
- `caso-de-estudio/`: caso de estudio de la biblioteca.
- `evaluacion/`: autoevaluación de 20 preguntas.

## Archivos

- `css/styles.css`: estilos, responsive, transiciones y animaciones.
- `js/app.js`: efectos progresivos y preferencia de movimiento reducido.
- `js/evaluacion.js`: lógica de la autoevaluación.
- `assets/images/`: imágenes y logotipos originales.
- `assets/documents/`: PDF y documento DOCX originales.
